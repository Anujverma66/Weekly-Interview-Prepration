## ▶️ How to Run the Programs

To run and check what each JavaScript file in the DSA folder does:

### 🌐 Method 1: Run in Chrome

1. Create an `index.html` file.
2. Add your JavaScript file using:

```html
<script src="two-sum.js"></script>
```

3. Open `index.html` in Chrome.
4. Open Chrome DevTools using `F12` to check console output.

### 💻 Method 2: Run using Node.js

Install Node.js if you haven't already.

Run a JavaScript file from your VS Code terminal:

```bash
node two-sum.js
```
